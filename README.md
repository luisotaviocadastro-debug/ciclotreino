# CicloTreino 🏋️‍♂️

Diário inteligente de musculação mobile-first com progressão de carga dupla e ciclos contínuos de treino.

## Funcionalidades
- 🔄 Ciclos contínuos de treinos
- 📈 Algoritmo de progressão dupla de carga e repetições
- ⏱️ Cronômetro de descanso com alertas sonoros e vibração
- 📱 Suporte completo a PWA (instalável no Android e iOS)
- ☁️ Sincronização em nuvem com Supabase (PostgreSQL)
- 💾 Funcionamento offline com armazenamento local
